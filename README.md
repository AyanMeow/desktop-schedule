# 桌面日程 · Desktop Schedule

Windows 桌面常驻的半透明日程管理小组件——无边框贴片"贴"在桌面上（非置顶、可被窗口遮挡），像桌面的一部分，随手查看与管理日程。

## 核心特性

- **日历视图**：周 / 双周 / 月切换，点击日期展开当日日程
- **完成激励**：勾选完成 → 删除线 + 随机鼓励语 + 艾露猫表情包气泡
- **成就系统**：19 枚成就（累计完成 / 连续坚持 / 单日爆发），未解锁显示 ？？？？？，解锁弹金色奖杯通知
- **DDL 提醒**：截止日期 5 级色阶着色 + 倒计时显示
- **天气**：当前天气 + 7 天预报（Open-Meteo，免费无 Key）
- **外观自定义**：6 套配色主题、透明度、字体、窗口位置大小记忆
- **桌面级驻留**：开机自启静默驻留托盘、抗 Win+D"显示桌面"隐藏
- **数据安全**：本地 SQLite 存储、日程导入 / 导出备份

## 技术栈

Tauri 2（Rust）+ Vue 3 + TypeScript + SQLite（rusqlite），构建为单文件便携 exe（静态链接 CRT）。

## 使用

Windows 10/11（需 WebView2 运行时，系统一般自带）。克隆后：

```bash
cd desktop-schedule
npm install
npm run tauri dev      # 开发
npm run tauri build -- --no-bundle   # 构建便携 exe
```

## v0.0.10（2026-08-17）

### 新增：自动更新
- **每日自动检查** GitHub 新版本（启动 1 分钟后首查，此后每 24 小时；设置中可关闭）
- **手动检查**：设置 → 版本与更新 →「检查更新」；发现新版本自动下载（右下角显示进度），完成后点「立即重启」完成覆盖更新，全程数据不受影响
- **完整性校验**：下载后 SHA-256 校验（校验值随版本公布），损坏自动重试下载
- **网络重试**：手动检查失败重试 3 次，定时检查重试 5 次
- **代理三档**：自动检测（读系统代理 + 探测常见本地代理端口并验证可用）/ 手动 / 直连；设置内「检测代理」按钮可立即验证
- 更新包托管于 GitHub Releases
- 注：自动更新自 v0.0.10 起生效，v0.0.9 及更早版本需手动下载本次更新一次

## v0.0.8（2026-08-17）

### 新增：成就系统
- 顶栏新增奖杯图标，点开成就面板：19 枚成就分三类展示，附累计/连续/单日统计概览
- **三类成就**：
  - 累计完成（10 枚）：每 50 条一档，50 → 500（初露锋芒 → 猫车之王）
  - 连续坚持（5 枚）：连续 3 / 7 / 14 / 30 / 100 天有完成日程
  - 单日爆发（4 枚）：单日完成 5 / 10 / 15 / 20 条
- **隐藏成就**：未解锁的成就名称与描述显示为「？？？？？」，只露进度条（如 37/50），解锁瞬间金色 Toast 揭晓名称
- **解锁即弹金色奖杯通知**（右上角，与鼓励语气泡错开），多枚同解显示「等 N 项」
- **防刷口径**：每条日程一生只计一次完成，反复勾选/取消不虚增计数；取消完成不会收回已解锁成就
- **老用户无缝升级**：首次启动按历史完成记录自动解锁已满足的成就（静默处理，不弹通知轰炸）
- 成就基于本地完成流水统计，历史数据从安装之日起全部有效

## v0.0.7（2026-08-14）

### 修复
- 贴片不再受「显示桌面」类操作影响：按 Win+D、Win+M 或点击任务栏"显示桌面"按钮后，贴片会在约 0.3 秒内自动弹回，不再消失
  - 背景：这类操作是系统对所有窗口做 DWM 级隐藏（最小化/cloak），无法从外部屏蔽，只能自动恢复
  - 实现：后台轻量监控（300ms 轮询，CPU 开销可忽略）检测到贴片被隐藏或最小化后立即恢复；同时禁用了贴片窗口动画，恢复过程基本无闪烁
  - 托盘菜单「显示/隐藏贴片」不受影响——主动隐藏不会被自动弹回

### 修复
- 修复启动初期点击控制面板「找到贴片 / 显示·隐藏贴片」会弹出未加载完整界面（默认主题 + 无日程）的问题
